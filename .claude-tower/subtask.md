# サブタスク: 画像添付機能ー②


## 実行指示（2026-11-19 14:11:13 UTC）

添付ボタンをファイル添付 と 画像添付のボタンに分けてほしい。

ファイル添付は今まで通り。

画像添付の場合は 既定の画像ファイル選択ダイアログで画像を選ばせた後、その画像のお絵かき ダイアロングを表示して欲しい。ダイアログ上でタッチ&ドラッグすると四角の赤い枠線を書くことができる機能と、タッチでその位置に赤い丸数字(①、②、③)を書くことができる機能を入れておいてほしい。それで画像加工したものを添付するようにして。
画像添付ファイルは同様に表形式で保存するが、ファイル名の代わりにサムネイルをちょうど良いサイズで表示するようにして。
