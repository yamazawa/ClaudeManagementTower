# サブタスク: CLIとMRの添付UIを共通化し、クリップボードの画像を貼付できるようにするー①

Issue本文の仕様に従って実装する。

- 共通化はMRのロジック（app/static/attachment.js）を元にし、CLIはそれを使う形にする。
- 文言は各JSの文言定数に集約し、色などの見た目の値はstyle.cssの変数にまとめる。
- クリップボードの判定はnavigator.clipboard.read()を使い、判定できない・許可されない環境ではボタンを常に表示する。
- CLIの添付一覧のAPIが無い場合はapp/routes/cli.pyに追加し、送信済みかどうかを返す。
- サーバー側を変更した場合はtestsにテストを追加し、./.venv/Scripts/python.exe -m pytest -q で確認する。
- コミットは「UI共通化」「クリップボード貼付」「CLIの送信済み表示・絞り込み」の単位で分ける。
- 画面での動作確認は人間が行うため、確認手順を報告に記載する。
